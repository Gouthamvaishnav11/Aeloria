Introduction to Aeloria

Aeloria is a modern cloud deployment platform designed to simplify how developers host their websites and full-stack applications on the World Wide Web. With seamless GitHub integration and automated testing, Aeloria makes deployment fast, secure, and reliable.

Our platform is built for developers who want to focus on writing code rather than managing infrastructure. Whether you're deploying a simple static site or a complex full-stack application, Aeloria provides the tools you need to get your project online quickly and safely.

Key Benefits

  • Seamless GitHub Integration: Connect your repositories in seconds and deploy automatically on every push.
  • Automated Testing: Ensure your code is production-ready with our built-in testing framework.
  • Global CDN: Deliver your content quickly to users around the world.
  • SSL Certificates: Automatic SSL provisioning for all deployments.
  • Custom Domains: Easily connect your own domain names.
  • Real-time Monitoring: Track performance and uptime with detailed analytics.

Getting Started

Welcome to Aeloria! This guide will walk you through the process of setting up your account and deploying your first application.

Step 1: Create an Account

Visit aeloria.com/signup to create your free account. You can sign up using your email address or through GitHub.

Step 2: Connect Your GitHub Account

After logging in, you'll be prompted to connect your GitHub account. This allows Aeloria to access your repositories and deploy them automatically.

Note

Aeloria only requires read access to your repositories. We will never modify your code without your permission.

Step 3: Import a Repository

Once connected, you can import a repository from GitHub:

  1. Click the "New Project" button in your dashboard
  2. Select the repository you want to deploy
  3. Configure your project settings (we'll cover this in detail later)
  4. Click "Deploy"

Aeloria will automatically detect your project type and suggest optimal settings. You can customize these settings before deploying.

GitHub Integration

Aeloria's deep GitHub integration is one of its most powerful features. This section explains how to make the most of this integration.

Repository Permissions

When you connect your GitHub account, Aeloria requests the following permissions:

  • Read access to repositories: Allows Aeloria to clone your code and deploy it.
  • Read access to organization repositories: If you want to deploy repositories from organizations.
  • Webhook access: Allows Aeloria to create webhooks that trigger deployments when you push changes.

Automatic Deployments

By default, Aeloria creates a webhook in your repository that triggers a deployment whenever you push to the main branch. You can customize this behavior:

  • Deploy on specific branches: Configure which branches should trigger deployments.
  • Manual deployments: Disable automatic deployments and deploy manually from the dashboard.
  • Deploy on pull requests: Automatically deploy preview versions when pull requests are created.

GitHub Actions Integration

If you're using GitHub Actions, you can integrate Aeloria into your CI/CD pipeline:

- name: Deploy to Aeloria
  uses: aeloria/deploy-action@v1
  with:
    api-token: ${{ '{{' }} secrets.AELORIA_API_TOKEN {{ '}}' }}
    project-id: your-project-id

Automated Testing

Automated testing is a core feature of Aeloria that ensures only quality code reaches production. This section explains how to configure and use testing in your deployments.

Supported Testing Frameworks

Aeloria supports a wide range of testing frameworks out of the box:

Language Framework
JavaScript/TypeScript Jest, Mocha, Jasmine, Cypress
Python Pytest, Unittest
Ruby RSpec, Minitest
Java JUnit, TestNG
PHP PHPUnit
Go Testing, Ginkgo

Configuring Tests

Aeloria automatically detects your testing framework based on your project structure. If you need to customize the testing configuration, you can add a aeloria.yml file to your repository:

test:
  command: npm test
  directory: /app
  timeout: 30000
  coverage:
    enabled: true
    threshold: 80

Test Results

After each deployment, you can view detailed test results in your Aeloria dashboard, including:

  • Pass/fail status for each test
  • Test execution time
  • Coverage reports (if enabled)
  • Error messages and stack traces for failed tests
Pro Tip

Set up Slack or email notifications to be alerted when tests fail, so you can fix issues quickly.

Deployment Process

Understanding the deployment process will help you troubleshoot issues and optimize your workflow. This section explains each step in detail.

Deployment Flow

When you push changes to your repository, Aeloria follows this process:

  1. Trigger Detection: The webhook in your repository notifies Aeloria of the push.
  2. Code Checkout: Aeloria clones your repository into a build environment.
  3. Dependency Installation: Required dependencies are installed based on your project type.
  4. Build Process: Your project is built according to the build commands specified in your configuration.
  5. Automated Testing: Tests are run to validate your code.
  6. Asset Optimization: Static assets are optimized for performance.
  7. Deployment: Your application is deployed to our global infrastructure.
  8. Health Check: Aeloria verifies that your deployment was successful.
  9. Notification: You're notified of the deployment status.

Build Configuration

Aeloria automatically detects your project type and sets appropriate build commands. You can customize these in your project settings or with a aeloria.yml file:

build:
  command: npm run build
  output_directory: dist
  install_command: npm install

Deployment Environments

Aeloria supports multiple deployment environments:

  • Production: Your live application accessible to users.
  • Preview: Temporary deployments for each pull request or branch.
  • Staging: A testing environment that mirrors production.

Environment Variables

Environment variables allow you to configure your application without hardcoding values in your code. This section explains how to manage environment variables in Aeloria.

Setting Environment Variables

You can set environment variables in your project settings:

  1. Navigate to your project in the Aeloria dashboard
  2. Click on the "Settings" tab
  3. Select "Environment Variables"
  4. Add your variables with their values
  5. Click "Save"

Environment Types

Aeloria supports different types of environment variables:

  • Build Variables: Available during the build process.
  • Runtime Variables: Available to your application when it's running.
  • Preview Variables: Only available in preview deployments.

Accessing Variables in Your Code

How you access environment variables depends on your programming language:

# Node.js
const apiKey = process.env.API_KEY;

# Python
import os
api_key = os.environ.get('API_KEY')

# Ruby
api_key = ENV['API_KEY']

Custom Domains

Custom domains allow you to serve your application from your own domain name. This section explains how to set up and manage custom domains in Aeloria.

Adding a Custom Domain

To add a custom domain to your project:

  1. Navigate to your project in the Aeloria dashboard
  2. Click on the "Domains" tab
  3. Click "Add Domain"
  4. Enter your domain name (e.g., example.com)
  5. Click "Add"

DNS Configuration

After adding your domain, you'll need to configure your DNS settings. Aeloria will provide you with the DNS records to add:

  • ALIAS or CNAME record: Points your domain to Aeloria's servers.
  • TXT record: Used for domain verification.

SSL Certificates

Aeloria automatically provisions and renews SSL certificates for all custom domains using Let's Encrypt. This process is completely transparent to you.

Note

It may take a few minutes for DNS changes to propagate and for your SSL certificate to be issued.

Monitoring & Analytics

Aeloria provides comprehensive monitoring and analytics to help you understand your application's performance and usage. This section explains how to use these features.

Performance Metrics

Aeloria tracks key performance metrics for your application:

  • Response Time: How long it takes for your application to respond to requests.
  • Uptime: The percentage of time your application is available.
  • Throughput: The number of requests your application handles per second.
  • Error Rate: The percentage of requests that result in errors.

Real-time Monitoring

The Aeloria dashboard provides real-time monitoring of your application:

  • Live request logs
  • Real-time performance charts
  • Current server status

Alerts and Notifications

You can set up alerts to notify you when certain conditions are met:

  • High error rate
  • Slow response times
  • Downtime
  • Failed deployments

Alerts can be delivered via email, Slack, or webhooks.

Security Features

Security is a top priority at Aeloria. This section explains the security features we provide to keep your applications safe.

SSL/TLS Encryption

All traffic to and from your application is encrypted using SSL/TLS. Aeloria automatically provisions and renews SSL certificates for all deployments, including custom domains.

Web Application Firewall (WAF)

Aeloria includes a built-in web application firewall that protects your application from common security threats:

  • SQL injection
  • Cross-site scripting (XSS)
  • CSRF attacks
  • DDoS protection

Secure Build Environment

Your code is built in a secure, isolated environment:

  • Sandboxed build containers
  • Temporary build artifacts
  • Secure dependency installation

Access Control

Aeloria provides fine-grained access control:

  • Team member management
  • Role-based permissions
  • Single sign-on (SSO) integration

API Reference

The Aeloria API allows you to programmatically manage your projects, deployments, and more. This section provides a comprehensive reference for all API endpoints.

Authentication

All API requests must include an API token in the Authorization header:

Authorization: Bearer your-api-token

You can generate API tokens in your account settings or using the form below.

Generate API Key

Create a new API key to authenticate your requests to the Aeloria API. Each key can be revoked at any time.

ael_sk_1234567890abcdefghijklmnopqrstuvwxyz

Security Warning: Treat your API key like a password. Do not share it publicly or commit it to version control.

POST
/api/v1/projects

Create a new project.

Request Body

Parameter Type Required Description
name string Yes The name of the project
repository string Yes The GitHub repository URL
branch string No The branch to deploy (default: main)
build_command string No The build command to run
output_directory string No The directory containing built files

Response Example

{
  "project": {

    "build_command": "npm run build",

    "created_at": "2023-01-01T00:00:00Z",
    "status": "created"
  }
}

Webhooks

You can configure webhooks to receive notifications about deployment events:

  • Deployment Started: Sent when a deployment begins
  • Deployment Succeeded: Sent when a deployment completes successfully
  • Deployment Failed: Sent when a deployment fails

Webhook payloads are sent as JSON POST requests to your specified URL. Each payload includes a signature header that you can use to verify the request came from Aeloria.

Rate Limits

The Aeloria API is rate limited to 100 requests per minute per API token. If you exceed this limit, you'll receive a 429 Too Many Requests response with the following format:

{
  "error": {
    "message": "Rate limit exceeded",
    "reset_time": "2023-01-01T00:10:00Z"
  }
}

Troubleshooting

This section provides solutions to common issues you might encounter while using Aeloria.

Deployment Failures

If your deployment fails, check the following:

  • Review the build logs in your dashboard
  • Ensure all dependencies are properly listed in your project
  • Check that your build commands are correct
  • Verify that your tests are passing

Common Build Errors

Error Solution
Module not found Check that all dependencies are listed in your package.json or requirements.txt
Build command not found Verify that your build command is correct in your project settings
Test failures Review your test code and fix any failing tests
Permission denied Ensure your repository is accessible to Aeloria

Performance Issues

If your application is slow or unresponsive:

  • Check the performance metrics in your dashboard
  • Optimize your database queries
  • Implement caching where appropriate
  • Consider upgrading your plan for more resources
